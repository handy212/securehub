SecureHub Project Cost Estimate

Prepared for project planning and budgeting | Currency: Ghana Cedis (GH₵)

This estimate covers completion, deployment, and initial stabilization of the SecureHub alarm management platform, including the backend API, Flutter mobile app, admin dashboard, Hikvision integration, notifications, testing, deployment, and project handover.

Total One-Time Project Cost: GH₵30,000

Detailed Cost Breakdown

Item Description Cost
Backend API completion Finalize Django/DRF APIs for authentication, sites, customers, alarms, events, commands, subscriptions, and related data flows. GH₵5,500
Hikvision integration Complete and test Hik-Partner/Hikvision connection, device synchronization, alarm commands, event handling, and live device validation. GH₵6,000
Mobile app completion Finalize Flutter app screens, login, site views, alarm controls, event history, notifications, account status, and API integration. GH₵6,000
Admin dashboard polish Improve the web dashboard for sites, customers, alarms, emergency services, subscriptions, logs, and basic management workflows. GH₵3,500
Notifications and emergency flow Configure push notifications, emergency request flow, alert handling, and customer notification settings. GH₵3,000
Testing and bug fixing Functional testing, API testing, mobile testing, live-flow checks, issue fixing, and basic regression checks before handover. GH₵3,000
Deployment setup Deploy backend to VPS, configure Gunicorn/nginx, Celery, Redis, PostgreSQL, SSL, environment variables, and basic backup setup. GH₵2,500
Documentation and handover Provide basic setup notes, admin usage guidance, deployment notes, and final project handover support. GH₵500
Total One-Time Project Cost GH₵30,000

Assumptions and Exclusions

  • Hikvision API credentials and test devices will be provided for integration testing.
  • DigitalOcean hosting is billed monthly and is separate from the one-time project cost.
  • Domain registration, SMS, WhatsApp, email provider charges, and app store fees are separate if required.
  • The estimate covers an initial production-ready launch, not unlimited future feature additions.
  • Major new features requested after approval may require a separate estimate.
